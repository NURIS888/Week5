# Week 5 — Solve and Analyze

This folder contains the Week 5 assignment: solving and analyzing two
LeetCode merge-sort problems.

## Contents

- [`sort-an-array/`](./sort-an-array/) — top-down (recursive) merge sort
  solution, trace, and complexity analysis for
  [Sort an Array](https://leetcode.com/problems/sort-an-array/description/).
- [`sort-list/`](./sort-list/) — top-down (recursive) merge sort solution
  adapted to a singly linked list (using the slow/fast pointer trick to
  find the middle), trace, and complexity analysis for
  [Sort List](https://leetcode.com/problems/sort-list/description/).

Each subfolder has its own `solution.py` (runnable with manual test
cases, plus a brute-force version kept only for cross-checking
correctness) and its own `README.md` with the problem explanation, a
step-by-step trace of the algorithm, challenges faced while developing
the solution (including approaches that didn't work and why), time/space
complexity with reasoning, and a reflection on possible improvements.
